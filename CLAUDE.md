# Project: Horacio Ruiz Portfolio (Print Monograph Aesthetic)

## Design System & UI/UX Rules:
1. Aesthetic: Elite, high-contrast, type-led print monograph. Art-directed, opinionated, editorial.
2. Colors: Pure Black (#000000) background, Pure White (#FFFFFF) text. No gradients. No shadows. Only flat colors. Gold (#D4AF37) is the only accent color for specific tiers.
3. Typography: Use Inter (Black/Bold) for oversized headlines via next/font. Use Playfair Display or Georgia for editorial serif body text. 
4. Layout: Asymmetric grids. Extreme whitespace. 1px solid white borders for dividers and cards. NO rounded corners anywhere. NO generic UI components.
5. Motion: Use Framer Motion. Animations must be smooth, cinematic, and editorial. Use clip-path reveals, staggered letters, and slight horizontal slides (x: 50 to 0) on scroll.
6. Code Quality: Write strict TypeScript. Modular components. No hardcoded strings in components; pass data via props.
